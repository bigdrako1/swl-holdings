# SooWooLife Holdings

Music, media and tech. Live from Nairobi.

The official SooWooLife Holdings website, featuring a founder’s note from Drako and
contact details.

**[swltrust.com](https://swltrust.com/)**

## Local development

A static site built with HTML and CSS. No build tools or dependencies are required.

```sh
python3 -m http.server 3180 --bind 127.0.0.1
```

Open [localhost:3180](http://localhost:3180/).

## Deployment

Changes pushed to `main` are published automatically to GitHub Pages. The custom domain
uses HTTPS; `www.swltrust.com` redirects to `swltrust.com`.

## Assets

The website uses the original SooWooLife Holdings logo and self-hosted DM Sans.
The font’s [SIL Open Font License](assets/fonts/OFL.txt) is included in the repository.
